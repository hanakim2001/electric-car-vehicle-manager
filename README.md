# 전기차 차량 관리 — FINAL v8 ONLINE

Android 앱 프로젝트입니다.

## 포함 기능
- 앱 제목: **전기차 차량 관리**
- EV CAR / CREATED BY Seung Hyun
- 홈 대시보드
- 충전요금: 일/월/년 표, 월별 그래프, kWh/주행거리/요금 기록
- 차량관리: km/개월 주기, 먼저 도래하는 기준으로 상태 표시, 사용자 항목 추가/수정/삭제
- 보증정보 메뉴
- 설정: 차량정보, 온라인 데이터, 부분/전체 초기화
- 초기화 확인 문구: "정말로 초기화하시겠습니까? 초기화 후 복구할 수 없습니다."
- 공공데이터포털 인증키를 입력하면 한전 공개 API 및 한전KDN CHA-ON 공개 API를 앱에서 직접 호출
- GitHub Actions Android Debug APK 빌드

## 온라인 데이터에 대한 정확한 범위
한국전력공사 '전기차 충전전력 월별 계시별 사용량 및 판매단가' Open API와 한전KDN 'CHA ON 전기차 충전 요금' 공개 API를 연결하는 실제 HTTP 호출 코드가 포함되어 있습니다.
공공데이터포털 API는 활용신청과 인증키가 필요합니다. 인증키는 Settings에서 입력하며 저장소에는 넣지 않습니다.

개인 사용자의 한전ON 고객 계정/청구서 데이터는 공개 API가 아니므로 앱에서 계정 비밀번호 등을 수집하지 않습니다. 실제 개인 청구금액 자동 연동은 한전이 제공하는 공식 인증/연계 방식이 공개될 경우 그 방식으로 추가합니다.

## GitHub 사용
1. ZIP을 압축 해제합니다.
2. GitHub 저장소에 모든 파일을 업로드합니다.
3. Actions → Build Android APK를 실행합니다.
4. 완료 후 Artifacts에서 `app-debug-apk`를 다운로드합니다.
5. 앱 설치 후 설정 → 온라인 데이터에서 공공데이터포털 인증키를 입력합니다.
